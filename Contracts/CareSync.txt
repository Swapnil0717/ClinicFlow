🚀 ClinicFlow Backend API Documentation
🌐 Base URL
http://localhost:5000/api/v1
🔐 AUTH APIs
✅ Register

POST

http://localhost:5000/api/v1/auth/register

Body:

{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "123456",
  "role": "PATIENT"
}
✅ Login

POST

http://localhost:5000/api/v1/auth/login

Body:

{
  "email": "john@example.com",
  "password": "123456"
}
✅ Google Login

POST

http://localhost:5000/api/v1/auth/google

Body:

{
  "idToken": "GOOGLE_ID_TOKEN"
}
✅ Verify Email

GET

http://localhost:5000/api/v1/auth/verify-email?token=YOUR_TOKEN
✅ Forgot Password

POST

http://localhost:5000/api/v1/auth/forgot-password

Body:

{
  "email": "john@example.com"
}
✅ Reset Password

POST

http://localhost:5000/api/v1/auth/reset-password

Body:

{
  "token": "RESET_TOKEN",
  "newPassword": "123456"
}
✅ Refresh Token

POST

http://localhost:5000/api/v1/auth/refresh

Body:

{
  "refreshToken": "REFRESH_TOKEN"
}
✅ Logout

POST

http://localhost:5000/api/v1/auth/logout

🔒 Headers:

Authorization: Bearer ACCESS_TOKEN
✅ Get Current User

GET

http://localhost:5000/api/v1/auth/me
🏥 CLINIC APIs
✅ Create Clinic

POST

http://localhost:5000/api/v1/clinics

🔒 Role: PATIENT

Body (example):

{
  "name": "City Care Clinic",
  "address": "Pune",
  "phone": "9999999999"
}
✅ Get My Clinic

GET

http://localhost:5000/api/v1/clinics/me
✅ Verify Clinic

PATCH

http://localhost:5000/api/v1/clinics/verify/CLINIC_ID

⏱ SLOT APIs
✅ Create Custom Slot

POST

http://localhost:5000/api/v1/slots/custom

Body:

{
  "date": "2026-04-01",
  "startTime": "10:00",
  "endTime": "12:00",
  "slotDuration": 30
}
✅ Create Recurring Slot

POST

http://localhost:5000/api/v1/slots/recurring

Body:

{
  "daysOfWeek": ["MONDAY", "WEDNESDAY"],
  "startTime": "10:00",
  "endTime": "12:00",
  "slotDuration": 30
}
✅ Get Available Slots

GET

http://localhost:5000/api/v1/slots/DOCTOR_ID?clinicId=CLINIC_ID&date=2026-04-01
