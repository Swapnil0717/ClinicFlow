🚀 ClinicFlow Backend API Docs
🌐 Base URL
http://localhost:5000/api/v1
🔐 AUTH APIs
1️⃣ Register
POST /auth/register
Body
{
  "name": "Pranav",
  "email": "pranavpathhare0987@gmail.com",
  "password": "123456",
  "role": "PATIENT"
}
2️⃣ Login
POST /auth/login
Body
{
  "email": "pranavpathhare0987@gmail.com",
  "password": "123456"
}
3️⃣ Verify Email
GET /auth/verify-email?token=YOUR_TOKEN
4️⃣ Forgot Password
POST /auth/forgot-password
Body
{
  "email": "pranavpathhare0987@gmail.com"
}
5️⃣ Reset Password
POST /auth/reset-password
Body
{
  "token": "RESET_TOKEN",
  "password": "newpassword"
}
6️⃣ Google OAuth
GET /auth/google
GET /auth/google/callback
👤 ADMIN APIs
1️⃣ Become Admin (temporary/debug)
POST /admin/become
Headers
Authorization: Bearer TOKEN
2️⃣ Verify Clinic
PATCH /admin/clinic/verify/:clinicId
3️⃣ Reject Clinic
PATCH /admin/clinic/reject/:clinicId
Body
{
  "reason": "Invalid documents"
}
4️⃣ Verify Doctor
PATCH /admin/doctor/verify/:doctorId
5️⃣ Reject Doctor
PATCH /admin/doctor/reject/:doctorId
Body
{
  "reason": "Not qualified"
}
🏥 CLINIC APIs
1️⃣ Create Clinic
POST /clinic
Body
{
  "name": "HealthCare Clinic",
  "address": "Pune"
}
2️⃣ Get Clinics
GET /clinic
🩺 DOCTOR APIs
1️⃣ Create Doctor Profile
POST /doctor
2️⃣ Get Pending Doctors (Admin)
GET /doctor/pending
📅 SLOT APIs
1️⃣ Create Slot
POST /slot
2️⃣ Create Recurring Slot
POST /slot/recurring
3️⃣ Get Slots
GET /slot
📅 APPOINTMENT APIs
1️⃣ Book Appointment
POST /appointments/book
Body
{
  "subSlotId": "SUBSLOT_ID"
}
2️⃣ Get Patient Appointments
GET /appointments/patient
3️⃣ Get Doctor Appointments
GET /appointments/doctor
4️⃣ Cancel Appointment (Patient)
PATCH /appointments/cancel/:appointmentId
5️⃣ Cancel Appointment (Doctor)
PATCH /appointments/doctor/cancel/:appointmentId
🔐 AUTH HEADERS (IMPORTANT)

For protected routes:

Authorization: Bearer YOUR_ACCESS_TOKEN
📦 RESPONSE FORMAT
✅ Success
{
  "success": true,
  "data": {}
}
❌ Error
{
  "success": false,
  "message": "Error message"
}
